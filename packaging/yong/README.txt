晨星键道 · 小小输入法 Windows 便携版
=====================================

启动
----
1. 将整个 yong 文件夹解压到不含特殊权限限制的位置。
2. 双击 yong.exe。
3. 按 Ctrl + 空格启用或关闭输入法。

常用按键
--------
- Shift：切换中英文。
- ; 和 '：选择第二、第三候选。
- - 和 =：候选翻页。
- Caps Lock：清空当前编码。
- Alt + .：切换简繁。
- Ctrl + /：反查编码。
- !：临时英文模式。
- i + 英文（如 ihello）、u + 连写全拼（如 uhao）、v + 二分编码、
  o + 键道单字码：使用与原生 Fcitx5 相同的静态命名空间。

目录
----
- .yong/yong.ini：小小输入法配置。
- .yong/mb/eosphoros/eosphoros.txt：由晨星键道词典自动生成的码表。
- .yong/skin：小小输入法自带皮肤。

更新与备份
----------
更新前请备份自己修改过的 .yong/yong.ini 和用户数据。不要直接编辑
eosphoros.txt；它会在新版本发布时重新生成。
普通词库没有删减；大码表使用小小后台线程加载，并关闭自动调频／自动造词。
